- The Mécano's collector and its end-of-support dataset (spec 12 §4, §7). The collector is operator code with no model, and it reads through the Mécano's connectors only. From the cluster it reads the images, the charts' labels, objects on deprecated apiVersions, cert-manager Certificates near expiry or not Ready, Argo CD Applications and Flux Kustomizations out of sync, and the cluster's version (the nodes', else the kube-apiserver static pod's). From Git it reads the manifests' index, with the Kustomize and Flux image overrides applied. Per component it records the version running, the version declared and the drift between them. It takes the newest version and the end of support from a `releases` connector when one answers, and otherwise from the dataset shipped with the release, saying "offline watch, current as of" its date. The dataset covers the Kubernetes minors and their removed apiVersions (kubernetes.io), and the cycles of cert-manager, Argo CD and Flux (endoflife.date). For agentgateway and kagent it gives only the latest release, with no end of support. Every entry names its source, and NOTICE credits both sources. Maintenances use the collector from a later release.
