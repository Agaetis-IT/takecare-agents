- The Mécano's collector and its end-of-support dataset (spec 12 §4, §7). The collector is operator code with no model, and it reads through the Mécano's connectors only. From each cluster it reads the images, the charts' labels, objects still on a removed apiVersion (probed only when the cluster's version is old enough and the replacement apiVersion is not served), cert-manager Certificates near expiry or not Ready, Argo CD Applications out of sync and Flux Kustomizations not Ready. It reads each cluster's version from its nodes only, so the cluster connector needs `addons.kubernetes.readNodes`; without it, a blind spot says so. From Git it reads the manifests' index, with the Kustomize and Flux image overrides applied. Per component it records the version running, the version declared and the drift between them. An object declared by several overlays matches when any of them agrees. It takes the newest version and the end of support from a `releases` connector when one answers, and otherwise from the dataset shipped with the release, saying "offline watch, current as of" its date. The dataset covers the Kubernetes minors and their removed apiVersions (kubernetes.io), and the cycles of cert-manager, Argo CD and Flux (endoflife.date). For agentgateway and kagent it gives only the latest release, with no end of support. Every entry names its source, and NOTICE credits both sources. Maintenances use the collector from a later release.
