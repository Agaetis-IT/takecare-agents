TakeCare Agents is installed in {{ .Release.Namespace }}.

The Doc is triggered by Alertmanager. Add this receiver to its configuration
(the token is in the Secret {{ .Values.alerting.existingSecret | default "takecare-alerting" }}, key token):

  receivers:
    - name: takecare
      webhook_configs:
        - url: http://takecare-alerts.{{ .Release.Namespace }}.svc:8080/v1/alerts
          send_resolved: true
          http_config:
            authorization:
              type: Bearer
              credentials_file: /etc/alertmanager/secrets/takecare-alerting/token

and mount that Secret into Alertmanager at that path. With helm template
or a GitOps tool, create the Secret yourself and set alerting.existingSecret:
a generated token would change at every sync.

Status: kubectl get takecare -A
